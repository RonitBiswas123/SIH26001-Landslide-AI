# Model

The model will be built only after the real landslide inventory, rainfall, terrain and other features have been validated.

Planned feature groups:

- Rainfall accumulation
- Rainfall forecast
- Terrain/elevation
- Slope
- Aspect
- Curvature
- Historical landslide evidence
- Land cover
- Distance to roads/streams
- Exposure
- Field/citizen evidence

Do not fabricate accuracy metrics.
